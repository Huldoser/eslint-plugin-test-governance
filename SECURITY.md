# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/Huldoser/eslint-plugin-test-governance/security/advisories/new).
You'll get a reply within a week. Once a fix is released, the advisory will be published with credit
to you, unless you'd rather stay anonymous.

Examples of what counts: a crafted test file or config that makes a rule hang (for example through
regular-expression backtracking), or anything that runs code the user didn't configure.
